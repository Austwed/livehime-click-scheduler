# 直播姬开关播助手

## 目标

在 Windows 上通过已登录的哔哩哔哩直播姬窗口，按用户校准的位置模拟点击“开始直播”和“结束直播”。工具不保存账号、密码、Cookie 或推流密钥。

## 当前状态

进行中。已实现本地 Windows 桌面程序与手动校准、定时直播、多个网页抢码预约、即时抢码测试、预约状态日志、浏览器/游戏独立录制、定时关播和结束后关闭直播姬；主页会汇总直播与抢码日志；待在真实直播姬界面完成用户验收。

## 主要功能

- F8 记录开关播共用按钮在直播姬窗口中的相对位置；窗口移动或缩放后仍能复用。
- 设置延迟开播秒数，或指定系统时间开播（默认 23:50:00；当天该时间已过则自动安排到明天）。默认直播时长为 73 分钟。
- 可添加多个独立网页预约：每条可分别填写启动时间的时、分、秒、浏览器路径、网页地址、随机点击最小/最大间隔和持续时间。所有网页共用内置 CSS 选择器，打开开发者工具控制台后立即运行内置脚本。该任务不依赖开播计划；若当天启动时间已过则安排到明天。只应对你有权操作的网页使用此功能。
- 网页自动抢码页可选自动关机；预约时会固定读取开关与时间，到达预设时间后创建 1 分钟关机倒计时。预约创建后相关选项锁定；“取消全部预约”可删除关机任务并中止倒计时。
- 主页保留预约状态日志，直播计划各阶段也会写入其中。
- 已移除自动睡眠、自动唤醒和唤醒后鼠标移动功能；网页预约执行期间电脑将保持当前唤醒状态。
- 任一“取消全部预约”按钮都会同时终止网页预约、自动关机和直播计划。
- 所有网页的抢码持续时间结束后，会自动将预约状态日志保存为桌面 TXT，并将整个虚拟屏幕截图保存为桌面 PNG。
- 计划开播前 10 秒启动直播姬；到点后等待窗口就绪并点击开播。结束时恢复窗口、点击关播，5 秒后请求正常退出直播姬，再等待 5 秒结束残留进程。
- 点击开播后先等待 5 秒，再依次启动四个应用槽位。每个已配置启动路径（`.lnk` 或 `.exe`）的槽位都会在打开窗口后等待 5 秒，再一次性回放自己的录制；若后面还有应用，回放完成后等待 2 秒再打开下一个。空路径槽位自动跳过。全部应用操作结束后，等待 5 秒启动《崩坏：星穹铁道》，再等待 5 秒并一次性回放游戏录制。游戏回放结束后保持不操作，直至自动关播。
- 默认提供四个应用槽位：夸克（`C:\Users\22320\Desktop\夸克.lnk`）、Google Chrome（`C:\Users\Public\Desktop\Google Chrome.lnk`）以及两个可自定义浏览器页面。应用槽位会按前台窗口的相对坐标记录与回放鼠标，浏览器窗口移动、大小改变后仍能在该窗口对应位置点击；鼠标仅记录并回放单击，不记录按下时长。游戏录制仍使用屏幕比例坐标，并保留鼠标与键盘按下/松开记录。
- 可选中任一表格行后点击“删除选中步骤”，删除任意右键或其他录制操作。
- 所有应用与游戏录制表格都有步骤编号；回放时状态栏显示正在执行的录制名称、步骤编号和操作类型。录制页通过可拖动分隔条让任一表格展开查看。
- 三页布局：主页“网页自动抢码”管理多个预约、即时测试和状态日志；“自动直播”合并直播参数与执行计划；录制页将浏览器/应用与游戏宏分为独立标签。
- 游戏启动测试模式：跳过直播姬和网页流程，只启动游戏，并在 5 秒后一次性回放游戏录制，然后等待设定时长结束。
- 定位测试模式：完整执行启动与回放流程，但只跳过直播姬“开播”和“关播”按钮的点击；应用与游戏录制仍会完整执行鼠标和键盘操作。
- 取消计划不会执行后续点击。
- 紧急关播按钮会再次确认，再模拟一次关播点击。
- 只对进程名为 `livehime.exe` 且具有主窗口的实例操作。

## 运行与构建

要求：Windows 10/11、.NET 8 Desktop Runtime（构建需要 .NET 8 SDK）。本工具会请求管理员权限，以便可靠地向直播姬发送输入；启动时请在 Windows 提示中选择“是”。

在本目录执行：

```powershell
dotnet run --project .\src\LivehimeClickScheduler\LivehimeClickScheduler.csproj
```

发布可移植版本：

```powershell
dotnet publish .\src\LivehimeClickScheduler\LivehimeClickScheduler.csproj -c Release -r win-x64 --self-contained false -o .\build\win-x64
```

## 使用方法

1. 打开直播姬并进入包含“开始直播”“结束直播”的常用页面，保持其窗口大小和页面布局固定。
2. 启动助手；将鼠标停在“开始直播”按钮正中央，按 F8；再将鼠标停在“结束直播”按钮正中央，按 F9。
3. 在“参数设置”页调整开播时间、直播时长和测试模式；在主页点击“开始执行”运行直播计划。直播姬会在实际开播前 10 秒启动。
4. 在“录制操作”页分别进入“浏览器/应用录制”或“游戏录制”。前者可选择应用槽位、填写名称和启动路径；两张表格均可用按钮收起或展开。游戏表格保留长按记录；应用表格只录单击。
5. 在“网页控制”页勾选任务开关，填写浏览器路径、网页地址、CSS 选择器、启动时间、随机间隔和持续时间；网页会按设定时间打开并立即随机点击目标元素，直至持续时间结束。回到主页点击“按时间启动网页控制”安排任务。
6. 顶部“操作说明”按钮汇总了热键、录制、网页控制和测试模式的使用规则。定位测试只会跳过直播姬开播、关播按钮的点击，其他录制照常执行。

## 已知限制

- 它只能发送鼠标点击，不能验证平台是否真正成功开播或关播。
- 关播点击后会等待 5 秒再请求直播姬正常退出；请求后再等 5 秒仍未退出则强制结束其进程树，未保存的直播姬设置可能丢失。
- 每个应用槽位只能启动用户填写且本机存在的 `.lnk` 或 `.exe` 路径；启动后是否成功加载到目标页面由用户自行确认。
- 网页随机点击依赖浏览器的 F12 与 `Ctrl+Shift+J` 快捷键；若浏览器策略禁用开发者工具或打开速度超过固定等待时间，需手动处理或重新安排。脚本在网页控制启动后立即开始，按设定范围随机间隔点击至持续时间结束。
- 已有的旧应用录制仍使用原屏幕坐标。为获得窗口自适应定位，请在 v15 中重新录制对应应用步骤。
- 直播姬升级、显示缩放、弹窗、窗口布局变化或按钮位置变化后，需要重新校准。
- 若开播或关播会出现二次确认弹窗，需手动处理；自动点击二次确认容易误操作。
