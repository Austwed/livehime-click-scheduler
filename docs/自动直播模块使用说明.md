# 自动直播模块使用说明

## 用途

“自动直播”页负责按计划启动直播姬、点击同一个已校准的开关播位置、依次打开已配置的浏览器/应用与游戏，并在设定时长结束后执行关播和关闭直播姬。

## 使用前准备

1. 安装哔哩哔哩直播姬，并使用你有权管理的直播账号手动完成登录和推流配置。
2. 直播姬应保持在常用的开播页面；应用更新、窗口缩放、页面弹窗或布局变动后，请重新校准。
3. 本自动直播互动流程按 5 个哔哩哔哩账号和对应 PC 浏览器窗口准备：请提前在各浏览器中完成登录，并按需要录制发弹幕、送礼物等页面操作。账号必须由你合法管理；请遵守平台规则，不要使用本工具规避账号、活动或频率限制。
4. 在“录制操作”页为每个浏览器/应用填写启动路径，并录制需要的页面操作。游戏录制与浏览器/应用录制分开管理。
5. 确认《崩坏：星穹铁道》启动路径存在；若不需要游戏录制，可保留空步骤。

## 校准与预约

1. 打开直播姬，鼠标移动到开关播共用按钮的中央，按 F8。
2. 在“自动直播”页填写直播姬启动路径和游戏启动路径，支持 `.lnk` 或 `.exe`。
3. 选择“按指定系统时间开播”，手动填写 `HH:mm:ss`；或取消勾选并填写延迟秒数。
4. 填写直播时长（秒）。默认 4380 秒即 73 分钟。
5. 如只想验证录制，可勾选“测试游戏录制”或“测试浏览器录制”；浏览器测试会遍历全部已配置的浏览器/应用槽位。它们会在点击“执行计划”后运行，不会进入完整直播流程。
6. 点击“执行计划”。可用“取消计划”终止未执行的等待和后续步骤。

## 执行顺序

1. 到达预约时间后等待 5 秒，再启动直播姬。
2. 再等待 5 秒，点击已校准的开关播位置。
3. 再等待 5 秒启动游戏；游戏加载 5 秒后回放游戏录制。
4. 游戏录制完成后等待 5 秒，按浏览器/应用槽位顺序打开并回放对应录制。
5. 到达直播时长后，再点击同一开关播位置完成关播；随后请求退出直播姬并清理残留进程。

## 注意事项

- 工具只能模拟鼠标和键盘输入，不能确认平台是否真的成功开播、关播、发弹幕或送出礼物。
- 涉及互动、礼物或账号操作时，请在第一次执行前使用测试功能逐项人工验收。
- 如果直播姬出现二次确认、系统权限提示或页面意外弹窗，需要由用户处理；工具不会绕过这些确认。
