# 网页自动抢码使用说明

## 用途

“网页自动抢码”页用于在指定时间打开一个或多个你有权操作的网页，并按每条预约设置的随机间隔运行页面内置连点动作。每条预约可使用不同浏览器、网页地址、启动时间、间隔和持续时间。

## 使用前准备

1. 安装可正常打开网页的 Edge、Chrome 或其他 Chromium 浏览器。
2. 在“浏览器启动路径”中填写浏览器 `.exe` 或本机快捷方式 `.lnk` 的完整路径。
3. 提前手动打开目标网站，完成你有权进行的登录、页面选择和必要确认。工具不会保存账号、密码、Cookie 或验证码。
4. 确认浏览器允许打开开发者工具；该功能依赖 F12 和 `Ctrl+Shift+J`。

## 配置预约

1. 打开“网页自动抢码”页，点击“添加网页”。
2. 勾选“启用预约”，填写预约名称、预约启动时间的时、分、秒，浏览器启动路径和目标网页地址。
3. 填写最小/最大随机间隔（毫秒）与连点持续时间（秒）。最小值不能大于最大值。
4. 点击“预约抢码”。当天时间已过的预约会顺延到次日同一时间。
5. 在下方“预约状态日志”核对时间、网站地址和连点参数是否正确。

## 自动关机

- 勾选“自动关机”后，可分别填写关机的时、分、秒；默认时间为 01:05:00。
- 点击“预约抢码”时，工具会按此刻的勾选状态创建 Windows 自动关机任务；到达预设时间后，系统会先启动 1 分钟倒计时再关机。时间已过会安排到次日。
- 预约创建后，自动关机、关机时间和预约后睡眠选项会锁定；取消预约会同时删除关机任务并中止已启动的关机倒计时。
- “强制取消关机”始终可用：即使之前已退出工具，重新打开后也可用它撤销 Windows 当前已预约的关机。

## 预约后睡眠

- 勾选“预约后睡眠”后，再点击“预约抢码”，工具会先等待 10 秒再让电脑进入普通睡眠；这 10 秒内可点击“取消预约”终止。
- 工具会在预约抢码后设置睡眠。若同时已创建直播预约，会在开播前 1 分钟唤醒；否则按最早抢码预约前 1 分钟唤醒。
- 最早预约不足 1 分钟、系统拒绝唤醒计时器，或电源设置禁用了唤醒定时器时，工具会保留预约但跳过睡眠，并在状态日志中说明原因。
- “取消预约”、关闭“预约后睡眠”开关或关闭工具都会撤销唤醒计时器。
- 唤醒后若 Windows 显示登录界面，必须由系统设置决定是否需要登录；工具不会尝试绕过密码、PIN 或锁屏。

## 测试与取消

- “抢码测试”会忽略预约时间，立即对所有启用的网页执行一次相同的网页控制流程。
- “取消预约”会停止尚未开始的预约和后续等待；已发送到浏览器页面的脚本由浏览器页面自行结束。
- 每个网页的连点持续时间结束后，工具才将该网页视为完成；所有启用网页完整完成后，会在桌面保存一份状态日志 TXT 和一张全屏 PNG 截图。抢码测试完成后同样会保存。
- 状态日志上方会显示当前流程状态与简略流程图；红点表示当前所处状态。

## 注意事项

- 只可用于你有权限操作的页面，并遵守网站规则、活动规则和频率限制。
- 页面加载过慢、浏览器策略禁用开发者工具、网站弹出确认窗口或页面结构变更，都会影响执行结果。
- 内置页面选择规则不在界面中编辑；请先用“抢码测试”验证目标页面是否适配。
